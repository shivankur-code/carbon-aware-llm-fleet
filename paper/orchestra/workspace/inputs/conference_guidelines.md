# Conference Guidelines

* **Venue type:** sustainable computing systems (computer architecture / systems workshop or full-paper preprint).
* **Page limit:** 12 pages for the main text, single column, 11pt, 1-inch margins. References do not count toward the limit.
* **Format:** single-column `article` class as given in the template; figures as PNG via `\includegraphics`; tables with `booktabs`.
* **Mandatory sections:** Abstract, Introduction, Background and Related Work, Lifecycle Model, Evaluation Methodology, Results, Discussion and Limitations, Conclusion.
* **Anonymity:** double-blind. No author names, affiliations, acknowledgements, funding, or links to code repositories.
* **Honesty requirements specific to this submission:** the study is a modelling study with public or assumed parameters; GPU measurements are prepared but not executed. Results that depend on placeholder GPU throughput, power, or CXL slowdown must be described as model-based and the dependence must be stated. No proprietary fleet data was used.
* **Submission deadline:** 2026-11-21 (use as the literature cutoff date).
